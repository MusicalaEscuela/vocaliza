# Vocaliza · Musicala

Guía breve de práctica vocal. Empieza con la rutina de cuatro ejercicios o abre la biblioteca de 14 ejercicios para trabajar respiración, calentamiento, vocales, articulación o afinación. Los ejercicios cantados incluyen una referencia instrumental opcional en tres alturas. La guía funciona sin cuenta, formularios, micrófono ni historial.

Abre `index.html` en un navegador. Para probar la instalación y el uso sin conexión, ejecuta `python -m http.server 8000` y abre `http://localhost:8000`. En producción, sirve los archivos desde HTTPS y conserva juntos el HTML, CSS, JavaScript, manifiesto y la carpeta `assets`.
